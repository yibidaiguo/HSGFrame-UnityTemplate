# 模块 · Combat（战斗）

一句话职责：单位的战斗状态与伤害结算，全部是纯 C#，零 UnityEngine。

## 公开面

| 类型 | 干什么 |
|---|---|
| `UnitTemplate` | 单位的静态模板：最大生命、基础攻防 |
| `UnitState` | 单位的运行时状态：当前生命、存活判定 |
| `DamageService` | 一次伤害的结算规则 |

三个文件不到五个，按《结构规范-代码》第二节先不开职责夹，全放模块根；涨过五个再分
`Contracts/ Events/ Data/ Utilities/`。

## 依赖了谁

- 不订阅任何模块的事件，也不引用别的模块。
- 被 `Tests/EditMode/LogicLayerEditModeTests` 与 `Solutions/Logic.Tests/HealthTests` 两侧覆盖，
  同一批源码在 Unity 与纯 `dotnet test` 下各跑一遍。

## 常用命令

```bash
dotnet test RebuiltRPG/Solutions/Logic.Tests/Logic.Tests.csproj
```
