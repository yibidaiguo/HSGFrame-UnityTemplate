> 总账在 [创作管线进度](../creation-pipeline-progress.md)。本文只装这一期的落地记录与验收证据。

## 这一期真正做的是什么

**不是「接通 Blender / Tripo」。** 两者都没有可用实例，真调用不在可验范围——
与 P2 批次 3 对 ComfyUI 的处置同一条线（锁定决策 23）。

做的是模型链路的**契约、加工计划与机检**：两个 driver 自述、模型类资产的规格补全、
八步加工计划的参数解析、五项机检、外加第二十二道门禁 `gate.model`。

## 为什么产的是「加工计划」而不是「加工报告」

子文档 06 §三·3 说加工是「按参数表执行八步，每步结果写加工报告」。
**没有 Blender，八步一步都执行不了**，写一份假报告正是决策 23 禁止的东西。

所以落的是**加工计划**：八步各自的参数从规格数据解析出来、定死、落盘。
它是加工报告的输入，也是「加工幂等」这条要求的落点——
**同一个资产请求 + 同一份规格数据，产出逐字节相同的计划**。
真 Blender 接上之后，报告是「照这份计划跑出来的结果」，计划本身不用改。

## Claude 在验收时抓到的一处链路断裂（本期最要紧的一条）

`ProcessingPlanBuilder` 原本只从**规格目录**取值。跑真命令时发现：
资产请求里 `轴心` 写的是 `底部`，产出的计划却填了目录里的 `中心`。

这意味着 **brief 收紧过的值永远到不了加工步骤**——P2 批次 2 建立的那套
「规格只能收紧不能放宽」（决策 27），在加工这一环整条断掉。
把 `最大面数` 从 3000 收紧到 1500 的 brief，加工计划照样按 3000 减面。

**这是我任务书的错**：参数来源那张表我写的是「→ 规格的 X」，执行后端照字面做了。
已由 Claude 改成：**优先取资产请求里的规格，请求没有该键才回落到规格目录**。
安全性有保证——请求里的规格是 `art.request` 按规格数据填的，放宽的值在建请求时
就没被采纳（`AssetSpecInspector` 把着）。

补了回归测试 `RequestSpecificationOverridesCatalogValue`，**先验过真能抓住**：
把修复改回去它立刻红（`Expected: "1500" / Actual: "3000"`）。

## 落地

**数据**：`Bridges/tripo/driver.json`（模型生成，线上）、`Bridges/blender/driver.json`
（模型加工，本地）+ `依赖清单.json`；`规范/基线/资产规格.基线.json` 的两个模型类型

`ModelMetrics`（度量从文件读）、`ModelInspector`（机检五项）。

**命令与门禁**：`art.plan` / `art.modelcheck` / `gate.model`（**第二十二道**）。

## 本期新增的锁定决策

44. **加工计划的规格值优先取资产请求，其次才是规格目录。** 只读目录会让 brief
    收紧过的值永远到不了加工步骤，决策 27 那条链路在这里断掉。
45. **加工计划必须幂等**：同输入逐字节相同。不许写时间戳、随机数、`Guid`、机器名、
    绝对路径。八个步骤对象**恒在计划里**，禁用只标记不删除——形状不稳定就谈不上逐字节比对。
46. **机检跳过的项必须报出来。** 规格里没有对应键时出一条「这一项没查」的 finding，
    不静默跳过——把没查的说成查过，是决策 42 那个错误的另一种长相。
47. **`包围盒上限米` 不进可覆盖清单。**
48. **`tripo` 的 `试跑` 是空串。** 线上形态、没密钥没账号，试跑命令还不存在；
    空着比填一个跑不了的命令名诚实。

## 执行后端这一轮报上来的三件事（一件是我任务书写错）

1. **规格键名我写错了——这是我的错。** 任务书说模型类型的规格键是 `目标面数` / `pivot`，
   基线里实际是 **`最大面数` / `轴心`**。我先前读基线时终端把中文显示成了乱码，
   就照子文档正文写了。它**按现场键名实现、按任务书命名计划参数**，并把这处出入报了上来。
   处置是对的：计划参数名 `目标面数` / `pivot` 是给 Blender 那侧看的，
   规格键名 `最大面数` / `轴心` 是数据来源，SkipReason 与 finding 里用的是现场键名——
   追「这个 3000 是哪来的」时指得回去。
2. **`$TEMP` 在沙箱里被重定向进仓库内的 `tmp/`。** 它发现后改用真实 Windows 临时目录，
   并说明曾误写进仓库一次、已清干净。Claude 复查过：`tmp/` 不存在。
3. **全量 `gate.ps1` 没跑**，因为新增测试文件要先由派活方登记进基线。如实说明了。
