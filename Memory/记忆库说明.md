# 记忆库说明

记忆库是随 git 走的一事一文件记录，用来沉淀「写不进检查器、但踩过一次就值钱」的东西。

## 放什么

- **项目约定**：标识符规则、提交标记、资产落地方式这类团队共识。
- **踩过的坑**：复现步骤 + 根因 + 怎么绕，下次少交一次学费。
- **外部资源指针**：关键文档、ADR、上游仓库的位置，不复制内容只给链接。

## 不放什么

架构决策与理由归 `Docs/决策记录/`，那里才走正式 review；记忆库只放约定、坑和指针。

## 三条规矩

- **一事一文件**，文件名用中文，一眼知道讲什么。
- **每条开头一句话摘要**，扫目录就知道要不要点进去。
- **写入时去重**：先查有没有讲同一件事的文件，有就改那条，不另开新文件。
