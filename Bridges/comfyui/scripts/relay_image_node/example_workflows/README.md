# 两份示例工作流

把 `.json` 直接拖进 ComfyUI 画布就能打开（不用「导入」菜单）。
装完节点包之后**要重启一次 ComfyUI**，否则打开时会报「节点类型不存在：RelayImage」——
ComfyUI 只在启动时扫一遍 `custom_nodes`。

| 文件 | 图长什么样 | 走哪个接口 |
|---|---|---|
| `relay-txt2img.json` | 中转生图 → 保存图像 ＋ Preview as Text | `/images/generations` |
| `relay-img2img.json` | 加载图像 → 中转生图 → 保存图像 ＋ Preview as Text | `/images/edits` |

两份都把「账」那个输出接到了 `Preview as Text`。那一格会写清**这次到底用了哪个模型、凭什么是它**
（点名的 / 本机配置钉死的 / 「自动」从清单里挑的），以及图是从 `b64_json` 还是 `url` 取回来的。
出了怪图先看它，比猜快。

`relay-img2img.json` 里的 `LoadImage` 默认指着 ComfyUI 自带的 `input/example.png`，
所以拖进去不用改就能跑；换成自己的图直接在那个节点上传。

## 三个格子怎么填

- **模型**：清单来自 `bridge.probe --Driver oaiimage`，不是节点自己探的。换了中转地址要重探一次，
  回来按 `R` 刷新节点定义才看得到新清单。选「自动」的含义见上面那句「账」。
- **尺寸**：**留空就一个 `size` 参数都不发**，由中转按它自己的默认来。各家模型认的档位不一样，
  填一个它不认的会直接被判「参数非法」。要填就写成 `1024x1024` 这种。
- **张数**：对应接口的 `n`。一次回来多张时尺寸必须一致，不一致节点会当场报错而不是悄悄只留第一张。

## 这两份图出来的东西不入库

它们只是图，没有资产请求、没有溯源边车、`art.regenerate` 复现不了。
要入库的正式资产走配方那条路（`/art-recipe` 那份技能里有判据与步骤）。
