# 模块 · Level（关卡）

一句话职责：把关卡定义（区块 + 逻辑实体摆放）在「纯数据」与「Unity 场景」两种形态之间往返。

## 公开面

| 类型 | 在哪 | 干什么 |
|---|---|---|
| `LevelDefinition` / `LevelChunk` / `LogicEntityPlacement` / `LevelVector3` | `Data/` | 关卡的纯数据形态，零 UnityEngine |
| `LevelSerializer` | `Data/` | 关卡数据与 JSON 文本互转 |
| `LevelValidator` / `LevelDataException` | `Data/` | 关卡数据的合法性校验与错误四要素 |
| `LevelRepository` | `Data/` | 按关卡 id 取关卡定义 |
| `LogicEntityMarker` / `EntityParameterEntry` | `View/` | 场景里标记「这个物体是哪个逻辑实体、带什么参数」的 MonoBehaviour |

`Data/` 归 `Game.Logic`；`View/` 靠 `Game.View.asmref` 归并进 `Game.View`。

## 依赖了谁

- 不订阅任何模块的事件，也不引用别的模块。
- 反向：`Toolkit.Editor` 的 `LevelSceneBuilder` / `LevelSceneExporter` 同时用 `Data/` 与 `View/`，
  在「场景 ↔ 关卡 JSON」两个方向上做转换。

## 常用命令

```bash
pwsh -NoProfile -File RebuiltRPG/Tools/Cli/unity-cmd.ps1 -ExecuteMethod Template.Toolkit.Editor.LevelSceneCommandLine.ExportFromCommandLine
```
