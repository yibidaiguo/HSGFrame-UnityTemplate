# 创作管线 · P7 批次 1「离风格报告」日志

> 总账在 [创作管线进度](../creation-pipeline-progress.md)。本文只装这一批的落地记录与验收证据。

## 这一批真正做的是什么

子文档 06 §五那句「离风格报告：对已入库资产算色板距离（资产主色聚类 vs 定稿色板
最小距离和），排序出 top-N；**只报告不自动行动**」。

要做这件事，先得有**图像解码能力**——而这个仓库里一点都没有。
所以本批从零写了一个最小 PNG 解码器：不引 NuGet、不用 `System.Drawing`
（跨平台不可用），inflate 借 .NET 自带的 `ZLibStream`。

## 为什么解码器宁可拒绝也不硬解

Adam7 隔行、非零压缩法/滤波法、非调色板类型的低位深、类型 1/5 保留值——
**一律如实拒绝并写清原因**（决策 23）。硬解出一张错的图，
比拒绝糟得多：错的图会一路算出一个看着很正常的色板距离，没人看得出它是假的。

执行后端**多拒了一档**，判断是对的：非调色板类型带 `tRNS`。
灰度/真彩的 `tRNS` 是「某个样本值算透明」的两字节语义，
与调色板逐索引 alpha 完全不同；不拒就会把透明信息硬当成不透明。

**CRC 不校验**，这一条写在类注释里——不说明的话，下一个人会以为校验过了。

## 聚类为什么一个随机数都不许有

k-means 的标准播种是随机的。**随机在门禁里没法验**：同一张图两次跑给出不同色板，
测试就写不出来，真出问题时也没法复现「当初聚出来的是哪几色」（决策 58 同源）。

所以播种写死成确定性的：颜色按 (频次降序, 十六进制序数序) 排，
第一个质心取头一个，之后每个取「到已选质心最小 ΔE ≥ 12」的第一个。
抽样也是固定步长而非随机采样，Lloyd 迭代中距离相等归下标小的簇。

**质心在 Lab 空间取均值**，不是 RGB 均值——RGB 均值在感知上会往灰里偏。
距离用 CIELAB ΔE76，不是 RGB 欧氏距离。

## 「没算成」与「符合风格」是两回事

定稿色板读不成、图解不开、全透明——**一律进 `Skipped` 并写清原因**，
绝不产出一个「距离 0」的排名（决策 42）。
没有色板却给出「距离 0」，等于告诉人「这批资产全都符合风格」，
而真相是根本没比过。

跳过的项**必须逐条列出来**（决策 46）。

## 已知缺口（不阻塞，记着）

- **Adam7 隔行 PNG 解不了。** 真资产里出现隔行图就会被跳过（有明确原因，不会假绿），
  要支持得再写一遍 Adam7 的七趟重组。
- **只吃 PNG。** JPG / WebP 都解不了——资产页允许的后缀里有它们。
- **ΔE76 是最老的那版色差公式**，在饱和色上与人眼感觉有偏差。
  要更准得上 ΔE2000，但那要更多的校准样本才说得清值不值。
- **阈值全是拍的**：播种间隔 ΔE ≥ 12、抽样上限 20000、迭代 30 轮、
  透明判据 alpha < 128，**没有一个是用真实资产校准过的**。
- **没有「离风格到什么程度算问题」的判据。** 报告只排序，不下结论——
  这是刻意的（只报告不自动行动），但意味着还得人去看。
- **没接进面板**（排在 P7 批次 3 的资产页离风格列）。
