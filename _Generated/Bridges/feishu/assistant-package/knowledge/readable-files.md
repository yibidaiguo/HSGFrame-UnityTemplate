# 你能读哪些文件

要看某个文件的内容时，填「要什么」: "读代码"，把下面的路径写进「读代码请求.文件」（一次最多 6 个）。

**路径照抄这份清单，别自己拼**——拼错了引擎只会回一句「这个文件不在」，一轮白花。
