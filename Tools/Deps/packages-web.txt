# 内置依赖清单·网页资源那一档（fetch-web.ps1 读这份）
#
# 每行三列，用制表符分隔：落地文件名<TAB>版本<TAB>下载地址。
#
# 这里放的是**给浏览器用的 js/css**，不是给 dotnet 用的。它们不走 NuGet，
# 所以另立一份清单与一个取它的脚本，而不是硬塞进 packages.txt——
# 那份清单的每一行都要能交给 NuGet 解闭包，这几行不能。
#
# 为什么要内置而不是写个 CDN 地址：这些页面是**我们自己的 HTTP 服务发出去的**。
# 一个由本机服务托管、却要连外网才能显示的页面，坏起来的样子是「点开一片空白」，
# 而那时人第一反应会是「预览功能坏了」，不会想到是 CDN 连不上。
# 何况这台机器上国内域名与国外域名的通断本来就不一致（BUG-0003）。
