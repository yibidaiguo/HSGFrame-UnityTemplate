## 二、锁定的设计决策(改这些要重新走设计审查)

1. **C# 一律落 ASCII 目录。** 命名门禁的 `directoryNamePattern` = `^[A-Za-z][A-Za-z0-9_.]*$`,只作用于**含 `.cs` 的目录**。所以引擎代码住 `Tools/CreationPipeline/`,中文只许出现在纯数据目录(`Pools/专项/`)与文件名里。
2. **配置落 `Config/创作管线/`,不落 `Config/` 根**——偏离总纲 §七的写法。原因:`Config/` 已被 Luban 配置表占满(`Luban/` `Mirror/` `Schema/` `Tables/`),下游配置混进去两套语义会打架。
3. **schema 用自定义精简格式,不用标准 JSON Schema。** 标准 JSON Schema 表达不了「字段所有权」「锁定后可改」「状态机转换权限」这三样,而它们正是这套机器的核心。格式见批次 1 的 `Pools/Schema/基线/需求.schema.json`。
4. **模板仓库零池子内容。** `Pools/` 下只铺空目录骨架(`.gitkeep`)与**基线 schema**;`Requirements/` `Inbox/` `专项/` 一条真实数据都不许进。基线 schema 属于机器,跟模板走。
5. **密钥永不入库。** `Config/创作管线/本机.json` 进 `.gitignore`,共享的 `下游.json` 只存密钥**名**。
6. **飞书 API 不在可验范围。** driver 只落契约与离线产物(建表描述 JSON、配置包文件),真调用留桩;任何声称「已连通飞书」的验收结论都不算数。

## 三、门禁现场(踩过的坑,别再踩)

- **测试基线锁**:新增测试文件必须登记进 `Tools/Gates/Config/test-baseline.json`,否则 `gate.baseline` 红。该目录在 `reasonix.toml` 的 deny 里,**执行后端改不了,只能由 Claude 跑更新模式**:
  `run gate.baseline --arguments-file <{TemplateRoot, UpdateBaseline:true}>`
- **改动文件白名单**:`Doc/` `Pools/` `Bridges/` `_Tasks/` `_Generated/` 已于本轮补进 `gate-config.host.json`。
- **文档长度 200 行**:`Doc/策划美术工作流接入方案.md`(448 行)已加进 `documentExemptions`——它是总纲,细则已拆七份子文档,再拆是把总纲切碎。**其余文档一律仍按 200 行管,本文也是。**
- **缩写黑名单**:`Mgr / Cfg / Svc / Btn / Idx / Tmp / Utils / Ctx / Param / Attr / Conf` 逐词段查,标识符里不许出现。
- **公开类型必须有中文 `<summary>`**,否则命名门禁红。
- **新 csproj 必须加进 `Solutions/Template.sln`**,否则十秒级门禁根本编不到它,绿灯是假绿。
- **派活的任务书要落进仓库,命令行只给一句短指令。** 长任务书直接当命令行参数传给 `rx.py`,Reasonix 会把这一轮判成 plan 模式、给子代理套上 `constraint=no-mutation`,写盘与 `dotnet` 全被拒,表现成跑两分钟、`chars=0`、`exit=1`、磁盘零文件——看着像模型不行,其实是被策略封死了。实测分界线是**长度**(47 字符可写,1900+ 字符即锁),改措辞没用。可用写法:任务书放 `_Scratch/派活/任务-<批次>.md`,命令行写「读 <路径> 这份任务书,逐条落实,然后按它「返回什么」那节回报」。
