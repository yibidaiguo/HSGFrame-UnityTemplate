# 统一面板(创作管线子文档 04)

> 上游:总方案 §六。扩展 `Tools/Dashboard`(DashboardServer 同栈自托管 web)。

## 一、总原则的实现

- **零私有状态**:每页 = 文件读取器 + 渲染;刷新 = 文件监听(FileSystemWatcher)推送 + 手动刷新兜底。
- **按钮皆命令**:`POST /cmd {命令行}` → 面板起 CLI 子进程 → 输出回显;命令白名单(仅 task.* / pool.* / bridge.* / engine.* / conflict.* / spec.*)。
- **访问边界**:默认只绑 localhost;开局域网访问需显式配置并提示(面板能触发命令 = 能动仓库)。

## 三、任务页细节(列表 → 详情两级,同一页面)

**列表级**(首屏,看全局):每行 = 标题 / 类型 / 专项 / 阶段+子状态 / 进度条(工作项完成比)/ **当前等谁**(停在关卡=被推送人,运行中=引擎,排队=位次)/ 等待时长 / 预算概览。筛选:专项 / 状态 / **「等我的」**(置顶——打开面板第一眼是自己的待办)。

**详情级**(点行进入,看一切):
- 顶部:需求摘要、提出人、专项与各职责认领人、预算条。
- 阶段轴横向五格,当前格高亮;横幅:重规划中(黄)/ 熔断(红)/ 停在关卡(蓝)。
- 工作项 DAG:按依赖拓扑分层布局(层次即列),节点色 = 状态;点节点看详情(产物预览 / 日志尾)。
- **责任视图**:当前关卡推送给了谁、等了多久;历史裁决记录(谁在哪一关通过/打回)。
- 关卡按钮就地操作;实时日志复用 LogEventChannel,默认跟随当前工作项。
- 时间线:阶段流转 + 变更 + 打回历史——全部由状态文件 + git 渲染,零私有状态。

## 三·五、审查页(技术终审 UI)

- **终审队列**:按风险排序;行 = 需求标题 / 风险级 / diff 规模 / 预审发现数 / 等待时长。
- **审查视图**:审查包五件套——变更地图(树形,高危红标)、方案对照、预审报告、验收报告、按工作项分组的 diff(内嵌渲染;深审给 IDE/命令行等价物)。行内评论汇成 `关卡意见/终审-*.md`;按钮:合并 / 打回(带意见)/ 转接管。
- **放行策略配置**(程序职责操作):风险级 × 范围开关矩阵,基线锁死项灰显不可改;改动即写 `放行策略.json` + commit。
- **放行流水**:自动放行记录 + 随机抽查按钮(抽 N 条进审查视图)+ 一键 revert(生成回滚 PR,策略自动回落该范围人审)。

## 四、规范页 = 管理员界面

四块功能:

1. **生效规范浏览(分页)**:Tab = 项目级 | 业务级(按模块再分页)| 基线 | 方向;每条规则标来源层与执行档(代码/AI 判定/人审)。
2. **新增规则(人述 → AI 生成,不分级)**:对话框只有描述 + 可选业务归属——**没有级别选择**。`spec-author` 自动判级与判执行档(代码→AI 判定→人审顺位,见子文档 07 §三)→ **命中预览含落位提示**(「12 处命中;将作为业务级规范落在 规范/业务/钓鱼/」)→ 确认后落对应层级目录,存量入棘轮,一次 commit。
3. **晋升提案待批**:AI 从返工摩擦里提的规则(子文档 07 §六),批准/拒绝。
4. **方向文档管理**:项目总体方向、框架级原则、美术风格定稿——这类「定成什么样」的顶层文本在此浏览与编辑(编辑 = 写文件 + commit;它们进 provision,助手与方案阶段都读)。

## 五、下游页动态表单

driver.json 的 `配置schema`(string/number/bool/enum/secret)→ 控件映射;`secret` 写 `Config/本机.json`,界面只显「已配/未配」。「试跑」行内显示结果;本地形态多一块能力对账(缺项清单 + 安装指引)。
