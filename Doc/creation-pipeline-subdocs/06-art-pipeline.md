# 美术管线(创作管线子文档 06)

> 上游:总方案 §八。四域落地细则;人做的与 AI 做的走同一条管线。

## 一、资产请求(完整契约)

```json
{
  "id": "ASSET-0042-01", "需求id": "REQ-0042", "工作项id": "WI-0042-03",
  "域": "资产.生图", "资产类型": "图标",
  "规格": {"尺寸": [256,256], "格式": "PNG", "透明": true},
  "落点": "Assets/Game/ResourceArt/Icons/签到/",
  "命名": "icon_signin_coinbag",
  "描述": "七日签到每日奖励图标,金币袋",
  "风格锚点": {"定稿": "UI图标风格@v3"},
  "变体数": 6, "预算": {"调用上限": 20},
  "依赖": [], "契约版本": "1.0.0"
}
```

规格与落点不由 AI 即兴——由资产规格数据按资产类型给默认(`Specifications/Project/` 全局,`Specifications/Business/<模块>/` 就近覆盖),brief 只能收紧不能放宽(门禁核对)。
风格锚点缺省取所属专项的「默认锚点」(子文档 01 §七)——同专项资产自动风格一致,brief 显式指定时才覆盖。

## 二、生图链路(逐步)

1. **配方**:`Bridges/comfyui/recipes/icon@v5/` = workflow.json + mapping.json(请求字段 → workflow 节点参数)+ 锚点槽(参考图输入节点、LoRA 加载节点)。云变体 `Bridges/云生图/配方/图标@v2/` = prompt模板 + 参数;同名配方跨 driver **共享同一套锚点**。
2. **生成**:`art.generate` 装配 → 调 driver → N 变体落 `30-outputs/ASSET-xxx/变体/`,每张配溯源边车。
3. **机检预筛**:尺寸/透明/命名/格式;不合格移 `弃/` 并记原因,人眼只看合格品。
4. **contact sheet**:合格变体拼九宫格带序号 → 选片卡片(按钮:[1..N] / [换一批] / [我自己来])。
5. **换一批**:反馈词追加进 prompt(记入边车),预算计数;第 3 轮起卡片附提示「已 3 轮,考虑接管或调锚点」。
6. **接管**:人产物放 `变体/人工/`,哈希检测即为当选;人改即权威。
7. **入库**:`art.import` = 复制到落点 + 按规格数据写导入设置(图集分组/压缩/mipmap)+ 刷新 + 实机预览截图 `预览/<资产>.png` → 资产规格门禁。
8. **git 策略**:当选 + 边车 + 预览提交;`变体/` 目录 gitignore,但**全部变体的边车提交**——变体可由边车重生成,算力换体积。

## 三、模型链路(逐步)

1. 生成:模型生成 port → 粗模落 `变体/` + 边车。
2. 三视图:Blender 脚本批渲(前/侧/45°)拼 sheet → 选片,同生图 4–6 步。
3. 加工(幂等):按参数表(资产规格数据:目标面数/贴图尺寸/命名前缀)执行——导入 → 统一单位(米)→ pivot 归位(按资产类型定脚底/中心)→ 减面 → UV → 烘法线(可选)→ 命名 → 导出 FBX;每步结果写加工报告。
4. 机检:面数、材质数、贴图规格、**包围盒合理区间**(拦「进 Unity 大一百倍」)、骨骼数(若有)。
5. 导入 + 预览截图(三视角)→ 门禁。

美术手工模型:工作项标 `人工产出=true`,跳过生成段,从加工段进,门禁待遇一致。

## 四、动画(port 占位)

请求预留字段:骨架id / 动作描述 / 时长 / 循环。v1 两条实路:
- **2D 动效**:spec(节点/属性/曲线/时长)→ tween 配置资产(具体格式随宿主 UI 方案定);
- **库 + 重定向**:动作库登记文件(名称/骨架/标签)→ 匹配 → retarget → 剪辑参数落配置。

## 五、概念与定稿

- `art.explore`:多配方 × 放飞参数批量出图,只产 sheet 不入库;探索的 prompt 集合留档可回溯。
- 定稿产出:选中图自动聚类主色(k-means 8 色)→ 人调 → `final.json`(色板/参考图/负面清单/LoRA 引用)+ 版本 +1。
- 离风格报告:对已入库资产算色板距离(资产主色聚类 vs 定稿色板最小距离和),排序出 top-N;只报告不自动行动。
- LoRA(可选):参考图攒够量 → 训练任务 → LoRA 入 `定稿/<名>@vN/lora/`,配方锚点槽引用。

## 六、美术规范的三档(与 07 §三对齐)

- **代码档**(尺寸/POT/命名/面数/图集/落点):资产规格数据 + 检查器,钩子增量、gate 全量,硬红拦截;新资产类型 = 加一条数据。
- **AI 判定项**(「图标必须 Q 版」这类代码写不出的):规则自带判定提示词,验收阶段批量跑、按文件 hash 缓存不重判;**软黄**进验收报告,默认不拦、可按规则配置拦;跑成熟后走下沉通道转代码检查器(如「禁背景板」转 alpha 边缘检测)。
- **人审档**(纯审美):方向条目 + 设计池定稿,选片时人执行。

## 七、失败与重生成

- 溯源边车齐全 ⇒ 任何历史资产可 `art.regenerate` 复现(同 seed 同配方同锚点);配方或定稿升版后重生成 = 新变体走新版,旧边车保留旧版引用。
- driver 更换后:锚点在仓库,老配方标废弃保留,新配方从锚点重校准(先跑标准测试题:同一组 brief 生成对比页,人确认风格接得上再切主)。
