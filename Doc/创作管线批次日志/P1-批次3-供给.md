# 创作管线 · P1 批次 3「供给」日志

> 总账在 [创作管线进度](../创作管线进度.md)。本文只装这一批的落地记录与验收证据。

## 这一批真正做的是什么

把「合并 schema + 设计池 + 校验文案」渲染成下游可用的**离线产物**：建表描述、专项表、
校验错误文案、助手配置包、指纹。**一行网络调用都没有**（锁定决策 6：飞书 API 不在可验范围）。
`bridge.provision` 产出的是文件，不是接口调用。

## 实际落地（分三次派活）

**3A · 校验文案收口**（`Tools/CreationPipeline/`）

- `ValidationMessageCatalog` + `ValidationMessageEntry`：13 条规则 id → 中文文案模板，
  是拒收回贴与下游助手提示的**唯一来源**（子文档 02 §四「不会两张皮」）。
- `RequirementValidator` 的 13 处写死文案改成向 catalog 取，纯机械替换（diff 恰为 26 增 26 删）。

**3B · driver 自述与两个表描述**

- `Bridges/feishu/driver.json`：driver 自述，形状照子文档 05 §二。
- `BridgeDriverDescriptor`：读并校验自述；缺字段 / 名称与目录名不符 / 形态非法都抛中文异常。
- `ProvisionFingerprint`：schema 哈希与设计池汇总哈希（都是 SHA256 打**规范化文本**）、
  指纹读写、对账。
- `TableDescriptionBuilder`：合并 schema → 建表描述（字段清单 + 分类型三张表单）。
- `EpicTableBuilder`：职责清单 → 专项表（固定三列 + 每职责一个「认领.<职责>」人员多选列）。

**3C · 助手配置包与编排**

- `ProvisionPaths`：`_Generated/Bridges/<driver>/` 一族路径。
- `ValidationMessageExporter`：catalog → `校验错误文案.json`。
- `AssistantPackageBuilder`：系统提示 + 知识四件（设计池摘要 / 术语表 / 正反例 / 模块清单）+ 导入说明。
- `BridgeProvisioner`：编排，**指纹最后写**——中途失败不会留下一份自称新鲜的指纹。
- `Tools/Cli/CommandHost/Commands/BridgeCommands.cs`：`bridge.provision --driver <名> [--dry-run]`。
- 测试：`CreationPipeline.Tests` 从 76 条涨到 **113 条**。

| `_Generated/Bridges/<名>/助手配置包/` | `系统提示.md` + `知识/`四份 + `导入说明.md`，正文里不出现任何下游平台的名字 |
| `Pools/知识/` | 助手知识素材的落脚处：`术语表.json` / `正反例.json` / `模块清单.json`，**都可缺失**，缺了渲染成「暂无」 |

## 本批新增的锁定决策

11. **字段类型映射住 driver.json，不住 C#。** 供给引擎完全泛化，driver 名永远是参数——
    这是子文档 05 §六「下游边界门禁」能绿的前提。基线 schema 的类型写的是中文
    （`数组` / `对象`），所以映射表中英文键都要有。
12. **`_Generated/Bridges/` 的产物进 git。** 与锁定决策 4（模板仓库零**池子**内容）不冲突：
    生成层按数据分层表本来就 `进 git ✓（对账）`。产物进库，批次 4 的供给对账门禁才有牙——
    否则它在模板仓库里永远走「未供给」跳过分支，等于没有。
13. **指纹只比两个哈希，不比产物文件。** `生成时间` 不参与哈希，也不参与对账；
    指纹文件不存在判「未供给」= 跳过，不判红。
14. **「提出人」「管理员」是伪职责，不给认领列。** 它们在卡片路由表里是运行时才解析成
    具体人的占位，不是可被认领的工种（延续锁定决策 9）。专项表的认领列只有 `美术` / `程序` / `策划`。

## 本批修掉的三个缺陷（验收时发现，已修）

1. **`InboxEnvelope.cs` 的注释里写死了 `feishu`**——批次 4 的下游边界门禁会当场判红。
   改成「渠道名，取自下游 driver 的名称」。
2. **字段类型映射漏了中文键**——基线 schema 里数组/对象字段的类型写的是中文，
   英文键映射不上会静默退化成「文本」。driver.json 补了 `数组` / `对象` 两个键。
3. **专项表给伪职责也开了认领列**——见锁定决策 14。
