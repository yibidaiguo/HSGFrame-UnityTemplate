# 下游 Driver 框架(创作管线子文档 05)

> 上游:总方案 §七。定 port 接口、driver 自述、契约与能力对账。

## 一、Port 接口(命令集)

| Port | 命令 | 说明 |
|---|---|---|
| 需求编辑端 | pull / push / provision / comment | 增量拉取、状态回写、铺表与助手包、拒收回贴 |
| 消息卡片 | send(模板id, 数据) / 回调 → CLI | 模板:选片 / 关卡 / 冲突 / 完成 / 喊人 |
| 助手 | package / serve | 产配置包 / B 形态常驻服务 |
| 生图 | generate(请求) → 变体 + 边车 | — |
| 模型生成 | generate(请求) → 粗模 + 边车 | — |
| 模型加工 | process(粗模, 参数) → 合规资产 | 幂等 |
| 动画 | generate(请求) → 动画资产 | port 已定,实现延后 |
| 执行后端 | complete(提示, 上下文) → 文本 | 引擎内部使用 |

调用协议:CLI 子进程,stdin JSON 入、stdout JSON 出,退出码 0/非 0;错误格式 `{错误码, 人话, 可重试}`。

## 二、driver.json(自述)

```json
{
  "名称": "comfyui", "port": "生图", "形态": "本地",
  "契约版本": ">=1.0 <2.0",
  "配置schema": {
    "url": {"类型": "string", "默认": "http://127.0.0.1:8188"},
    "超时秒": {"类型": "number", "默认": 300}
  },
  "密钥字段": [],
  "试跑": "art.generate --driver comfyui --自检",
  "能力探测": "comfyui-caps",
  "实现": "bridge-comfyui"
}
```

- `形态: 线上|本地`;线上形态 `密钥字段` 列 key 名,值只进 `Config/本机.json`。
- 面板下游页按 `配置schema` 动态渲染表单——**加 driver 不改面板**。

## 三、契约与版本

契约文件(`Pools/Schema/基线/`):资产请求 / 溯源边车 / 同步记录。semver:加可选字段升 minor,改语义或删字段升 major。driver 自述声明支持区间,试跑第一步核版本,不匹配即红。

## 四、能力对账(本地形态)

- 探测输出:`{节点: [{名, 版本}], 模型: [{名, hash}], lora: [...]}`。
- 依赖声明:配方与请求的 `依赖` 数组。
- 对账:依赖 ⊆ 探测结果;缺项报告 = {缺什么, 来源(依赖清单里的 URL), 怎么装}。
- `Bridges/comfyui/依赖清单.json`:名称 + 版本 + 来源 + 可选安装命令;安装器风格学 HybridCLR——现装 + 装完打报告。大文件(模型 checkpoint)刻意不进仓库,清单进。

## 五、密钥与账号归属

- **原则:配置跟机器走,不跟成员走。** AI 调用全由引擎发起;成员只收卡片,零密钥零安装。
- **执行机**:跑引擎的机器,`Config/本机.json` 填全(Claude/云生图/模型生成 key、飞书应用 secret、ComfyUI 端点)——项目的「AI 钱包」,v1 只有一台,归管理员。
- **成员自跑任务** = 自己机器变执行机:项目 key(管理员发,项目出钱)或自带 key(自己出钱)二选一;消耗记录带 `{任务, 调用类型, 执行机标识}`,面板按需求/机器/账号汇总。
- **飞书**:项目一个机器人应用,secret 住执行机;成员与机器人的关系只是被推卡片(open_id 在成员表)。
- **接管**:人用自己的工具与账号产出,系统只认放回来的文件(边车标「人工产出」)——个人账号在系统边界外,不存在上交个人 key 的问题。
- 执行机迁移:新机器照面板「下游」页红点逐项填绿即完成。

## 六、下游边界门禁

- 扫描范围:引擎与管线层代码。
- 禁止串:自动收集全部 `Bridges/*/driver.json` 的名称,出现即红。
- 白名单:`Bridges/` 自身、`Config/下游.json`、面板下游页渲染代码。

## 七、新增 driver 的固定四步

1. `Bridges/<名>/` 建夹:driver.json + 实现(+ 配方,若生图类)。
2. `Config/下游.json` 把域指过去(或加为备用)。
3. 面板下游页出现新行 → 填配置 → 试跑绿(本地形态附能力对账绿)。
4. 跑下游边界门禁与供给对账 → 绿即接入完成。引擎、skill、面板全程零改动。

## 八、v1 driver 规划

| driver | port | 形态 |
|---|---|---|
| feishu | 需求编辑端 + 消息卡片 + 助手(package) | 线上 |
| comfyui | 生图 | 本地 |
| 云生图(即梦/万相,择一) | 生图(备用) | 线上 |
| tripo(或 meshy/混元3D) | 模型生成 | 线上 |
| blender | 模型加工 | 本地 |
| claude | 执行后端 | 线上 |
